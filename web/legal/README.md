# Pantry Party site (landing + Privacy + Terms)

Static pages served by nginx on Railway (project `pantry-party`, service
`legal`). `site/` is generated by `generate.py` and committed so deploys are
reproducible:

- `/` is the landing page, which doubles as the App Store **Support** and
  **Marketing** URL. Its copy lives in `generate.py`.
- `/privacy/` and `/terms/` are rendered from `docs/legal/PRIVACY.md` and
  `TERMS.md`, the source of truth (placeholders filled: app name, dates,
  contact email).

Regenerate after changing either legal doc, the landing copy, or screenshots:

```sh
pip install markdown
python web/legal/generate.py
```

App screenshots are optional. Drop `.png`/`.jpg`/`.webp` files into
`web/legal/screenshots/` (sorted by filename, e.g. `01-pantry.png`) and
regenerate; the landing page shows them in a scrolling strip. With no files
there, the section is omitted.

Deploy after regenerating:

```sh
railway up web/legal --path-as-root --service legal --detach
```

Apple App Store Connect wants the privacy-policy URL from this service
(`/privacy/`); the terms live at `/terms/`.
